# QA-план Hunter English — визуальное и функциональное тестирование

> Ветка `qa/visual-testing-phase`. Дата: 2026-10-05. Продукт: локальный SPA (Vite+React, hash-роутинг), данные — IndexedDB (Dexie), «бек» — офлайн-первичный; Supabase — только в проде (локально недоступен).

## 0. Цели и границы

**Цель**: полную проверку всех страниц/этапов/функций — найти «косо/криво» (вёрстка, UX-ловушки), функциональные баги, битые состояния. Фронт и бек-слой — раздельно.

**В границы входит**: все 16 маршрутов, флоу онбординга, урок (все 15 типов упражнений), SRS, Врата/экзамены, цитаты, разговорник, настройки, офлайн-поведение, экспорт/импорт.
**Вне границ**: реальный Supabase (нет локального инстанса; проверяем только деградацию без сети), реальные голоса (Piper-аудио уже записано — проверяется воспроизведение файлов), PWA-установка (проверяем SW-режим по косвенным признакам).

### 2.11. Сквозные UI-инварианты (глаза по скринам)

- контент по центру (уроки/лендинги), панели не разъезжаются на 1280 и 390;
- контраст текста (dim на surface-2), касаемость кнопок ≥44px на мобайле;
- таб-бар мобайл: 5 пунктов, активная подсветка;
- длинные строки (RU-переводы, названия тайтлов) не ломают сетку;
- фокус-стили видны при Tab-навигации (минимум на кнопках).

## 4. Технологии и инструменты

> **Правки по итогам ревью суб-агента (2026-10-05):** (1) тема dark — НЕ через localStorage (SettingsProvider перезапишет на дефолт): переключение select-ом в /#/settings и ожидание `document.documentElement.dataset.theme === 'dark'`; (2) offline — двухшагово: online-загрузка (SW ставится + прогрев) → `setOffline(true)` → reload; (3) сложные состояния (SR-7 долг, PT-3 плашка, RG-3 pass) — сидинг `card_states`/`item_progress` через `page.evaluate` (raw IndexedDB по схеме specs/06) или vitest-уровень; полный проход урока — уже покрыт юнит-драйвером LessonScreen.e01-pass, тур делает частичный проход для скринов; (4) эталоны ответов — скрипт читает `data/*.json` из Node (fs), не из браузера; (5) launch-арги: `--use-fake-device-for-media-stream --autoplay-policy=no-user-gesture-required --mute-audio`; «играет аудио» проверять `evaluate` (не скрином); (6) кулдаун 72ч — свежий контекст или `page.clock`; (7) онбординг-флаг — строка `'1'` через `addInitScript`; (8) импорт `{ chromium }` из `@playwright/test`; (9) скрины — после маркера готовности (настройки/данные загрузились, нет «Загрузка…»); (10) ST-5 экспорт — `page.waitForEvent('download')` + `saveAs`; (11) перед туром — `npm run check:i18n`; (12) `/#/srs/session` — не маршрут, сессия = состояние SrsScreen; (13) `/#/gates` без id → кейс RG-0 (E-D intro); S-FINAL-монолог имеет досрочное «Я закончил(а)».

| Задача | Инструмент | Почему |
|---|---|---|
| Функциональный фронт + скриншоты | **Playwright API** из `@playwright/test` (chromium) + скрипт `scripts/qa-tour.mjs` (контексты ×вьюпорт/локаль/offline, fullPage-скрины) | нулевые новые зависимости |
| Разбор скриншотов «глазами» | PNG в `test-results/qa/…`, чтение агентом | дёшево, без внешних сервисов |
| Тема dark / локаль en | через /#/settings (select), ожидание маркера | персист в Dexie meta |
| Сидинг профилей | FRESH — чистый контекст; GUEST — `addInitScript` localStorage `hunter-onboarding-done='1'`; ПРОГРЕСС — частичный UI-проход + `page.evaluate` для сложных состояний | честно где дёшево, `evaluate` где иначе долго |
| Бек-слой | vitest (613) + BK-кейсы туром | — |
| Supabase | локально не поднимаем; только BK-7 (деградация офлайн) | нет инстанса |
| Резерв | `@playwright/mcp` — только если упрёмся в несовместимое со скриптом | правило: зависимости по факту |

## 5. Процедура прогона

1. `npm run build && npm run preview` (прод-сборка, как в CI) — порт 4173.
2. `node scripts/qa-tour.mjs` — матрица скринов `test-results/qa/<context>/<page>.png` + лог событий (консольные ошибки страницы пишутся в `console.log` файла).
3. Разбор: агент читает PNG по чек-листу §2.11 + ожиданиям кейсов; находки — в `research/11-qa/FINDINGS.md` (severity, кейс, скрин).
4. BK-кейсы — точечные скрипты/ручные шаги тем же туром.
5. Итог: отчёт разработчику; явные P0-фиксы — отдельной веткой по обычному процессу.
