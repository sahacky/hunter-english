# Итоговое резюме ресёрча (M0)

Дата: 2026-09-27. Это сжатая выжимка из файлов `01`–`07`: принятые решения и открытые вопросы. Детали и источники смотри в соответствующих файлах.

## Кто и зачем
- Ученик: русскоязычный, уровень A0. Цель — **путешествия** (понимать на слух, отвечать). 1 час в день, старт строго с нуля, транскрипции не нужны.
- Продукт: **Hunter English**, веб-приложение (сначала десктоп, потом PWA на телефоне), интерфейс ru + en.

## Методика (01, 03)
- Комбинация методов: **короткое правило → 20–30 фраз RU→EN с нарастанием (метод Бебриса) → диктант → shadowing и ответы в микрофон → интервальные повторения (FSRS)**.
- Каждое слово учится во фразе, лучше всего в фразе из любимого сериала. Цитата показывается, только когда известно ≥ 90% её слов.
- Сроки (Cambridge GLH): A2 ≈ 6–7 мес., **B1 ≈ 12–13 мес.** (планка для путешествий), B2 ≈ 1,5–2 года.

**Ежедневный час:**

| Блок | Мин |
|---|---|
| Повторение | ~20 |
| Урок грамматики | 15 |
| Новые слова | 8 |
| Диктант | 8 |
| Речь | 7 |
| Бонус | 2–5 |

## Грамматика (01, 04)
- **8 основных времён** в порядке изучения: Present Simple → Present Continuous → Past Simple → will / be going to → Present Perfect → Past Continuous → Past Perfect → Present Perfect Continuous. Плюс модальные глаголы. Present Simple и Past Simple дают около 80% глаголов в речи.
- Скелет по уровням A1→B2 и мини-модуль пунктуации: 01 §5.
- **Ловушки для русскоязычных** (~20, в т.ч. `I go to home`): сквозной модуль, 03 §4.
- **Бебрис** (04): порядок уроков у него не копируем. Present Continuous, can и have got у него появляются только после ~550 видео; нет be going to, сравнений, there is/are, пунктуации, ситуаций для путешествий. Видео привязываем к нашим урокам **по теме** (таблица на 45 тем, E→S). Его контрольные используем как тренировку перед Вратами.

## Словарь (01, 07)
- Порядок: **NGSL-Spoken 721** (90% речи) → **NGSL 2 809** (92% текстов) → до ~5 000 по субтитрам (FrequencyWords).
- Переводы: **Wiktionary через kaikki.org**, группировка по значениям; для топ-1000 ручная курация.
- Примеры: Tatoeba. Неправильные глаголы: JSON на ~200 глаголов. Фразовые глаголы: PHaVE (150).
- Oxford 3000/5000 **не публикуем** (© OUP).

## Карточки SRS (01, 03)
- Алгоритм **FSRS** (`ts-fsrs`), retention 0.90.
- **15 новых в день** (~10 слов + 5 фраз), это даёт ~150 повторов (~20 мин). Защита от завала: после пропуска новые карточки урезаются.
- Для новичка 2 кнопки («Не вспомнил / Вспомнил»), 4 кнопки включаются в настройках (06).

## Упражнения и проверка (03)
- 14 типов упражнений (перевод текстом/голосом, собрать фразу, диктант, shadowing, cloze в цитате, найди ошибку, диалог-сценка…). Шаблон урока: 03 §9.
- Проверка ответов: сокращения эквивалентны; несколько правильных вариантов; опечатки засчитываются с подсветкой (кроме a/the, in/on, is/are…); кнопка «Я был прав».

## Цитаты (05)
- Язык простой: 90–93% слов входят в топ-1000.
- Сильные тайтлы: Supernatural (~6 000 реплик), GoT (~5 500), FMA (~4 100), Breaking Bad (~2 800), Stranger Things, Star Wars.
- Средние: The 100, Black Mirror, LOTR, Berserk. Слабые (только ручной сбор): AoT, JJK, Solo Leveling.
- На старте реально **450–700 отобранных цитат**, для MVP хватит ~300. 180 образцов уже есть в `data/quotes-sample.json`.
- Правила: только короткие цитаты с источником, ≤ 40–60 на тайтл, IMDb только вручную, без песен, видео и аудио.

## Голос (02) — ✅ выбран
- **Основной: Piper en_GB `cori` (high)**. Женский британский голос, датасет public domain.
- **Второй (мужской): Kokoro `bm_george`** (Apache 2.0) для разнообразия на словах и в диалогах.
- Всё озвучивается заранее (~75 МБ Opus), фолбэк — Web Speech API с en-GB-голосом.
- Микрофон: `SpeechRecognition` в Chrome/Edge, позже Whisper в браузере.

## Геймификация (02, 06)
- Ранги **E→D→C→B→A→S = A0→C1**. Повышение только через экзамен **«Врата»**.
- XP только за реальную работу; стрик с заморозками; ежедневные квесты; достижения по тайтлам.
- Не берём: сердечки/энергию, лиги, давление на чувство вины, штрафы.
- Стиль «System window» по мотивам Solo Leveling (без логотипов, артов и звуков из тайтла). Шрифты с кириллицей: Tektur/Russo One для заголовков, Onest/Golos Text для текста.

## Техника (02, 07)
- **Vite + React + TypeScript**, Dexie (IndexedDB, офлайн-first), ts-fsrs, react-i18next, vite-plugin-pwa, Vitest + Playwright.
- **Supabase**: вход через GitHub, Postgres + RLS. Синхронизация через очередь; `review_log` только добавляется.
- Репозиторий **приватный** `sahacky/hunter-english`. ⚠️ GitHub Pages для приватного репо требует Pro, хостинг решаем в M2.
