## 1. Сервер и авторизация

### Важная поправка: GitHub Pages не может быть сервером

GitHub Pages отдаёт только **статические файлы** (HTML/JS/CSS/JSON). Базу данных и логин на нём не запустить. Поэтому схема такая:

```
[ GitHub Pages ]  ← сайт (интерфейс, уроки, слова, аудио)
       │
       │  HTTPS-запросы из браузера
       ▼
[ Бэкенд-сервис ] ← логин + база данных с прогрессом
```

Код всего проекта лежит в GitHub, сайт хостится на GitHub Pages, а прогресс хранится во внешнем бесплатном сервисе.

### Варианты бэкенда

| Вариант | Что это | Бесплатно | Минусы | Вердикт |
|---|---|---|---|---|
| **Supabase** | готовый бэкенд: Postgres + авторизация (вход через GitHub/Google/почту) + API из браузера | 500 МБ БД, 50 000 пользователей, 5 ГБ трафика в месяц | бесплатный проект **засыпает после 7 дней без активности** (приходит письмо, будится в 1 клик) | ✅ **рекомендую** |
| Cloudflare Workers + D1 | свой мини-сервер на JS + SQLite | 100k записей/день, 5 ГБ | авторизацию писать самим | запасной вариант |
| Firebase | как Supabase, от Google | щедрый free | NoSQL, привязка к Google, в РФ возможны проблемы с доступом | ❌ |
| Свой VPS (PocketBase и т.п.) | свой сервер | нет, ~300–500 ₽/мес | надо администрировать | позже, если захочется |
| Прогресс в приватном GitHub-репозитории | вход через GitHub, прогресс коммитится в репо | да | для обмена OAuth-токена всё равно нужен мини-сервер; медленно; костыль | ❌ |

**Рекомендация: Supabase.**
- Вход через **GitHub-аккаунт** в одну кнопку (ложится на «мы на GitHub»).
- Row Level Security: каждый видит только свой прогресс.
- Засыпание не проблема: мы занимаемся каждый день, так что активность всегда есть.
- Размер: даже при 5000 слов × несколько типов карточек и логе всех ответов за год выйдет десятки МБ из 500.

**Офлайн:** прогресс пишется сначала локально (IndexedDB), потом синхронизируется с сервером. Если пропал интернет, занятие не прерывается.

### Что хранить на сервере

- профиль: XP, ранг, стрик, заморозки стрика, настройки (голос, скорость речи, лимит новых слов);
- состояние каждой карточки (FSRS: stability, difficulty, due, reps, lapses);
- лог ответов (для статистики и будущей оптимизации параметров FSRS);
- прогресс по урокам: пройден ли, результат контрольной.

## 2. Британский голос

### Варианты

| Вариант | Качество | Британский? | Стоимость | Оффлайн | Замечания |
|---|---|---|---|---|---|
| **Web Speech API (системный голос браузера)** | от среднего до хорошего | Chrome: «Google UK English Male/Female». Edge: **Microsoft Sonia/Ryan/Libby/Thomas (Natural)**, очень хорошие | бесплатно | нет (это онлайн-голоса) | набор голосов зависит от браузера и ОС; в Linux-Chrome может не быть UK-голосов |
| **Заранее записанные mp3 (Piper, en_GB)** | хорошее, одинаковое везде | ✅ `cori` (high, public domain), `alba` (CC-BY 4.0), `northern_english_male` (CC-BY-SA) | бесплатно | ✅ | генерим при сборке, кладём в репо |
| **Заранее записанные mp3 (Kokoro)** | хорошее | ✅ `bf_emma` (B-), `bm_george`/`bm_fable` (C) | бесплатно, Apache 2.0 | ✅ | британские голоса у Kokoro слабее американских |
| edge-tts (Microsoft Neural через неофициальный API) | **лучшее** | ✅ en-GB-SoniaNeural, RyanNeural | бесплатно | ✅ после генерации | неофициальный доступ, лицензия на распространение mp3 серая, так что в **публичный** репо лучше не класть |

### Рекомендация: гибрид

1. **Все фразы курса (уроки, слова, цитаты) озвучиваем заранее** британским голосом Piper `cori` (high) и/или `alba`. Звук одинаковый на всех устройствах, работает мгновенно и офлайн, лицензии чистые.
   - Объём: ~10 000 фраз × ~2,5 с в Opus 24 кбит/с ≈ **~75 МБ**. Это в пределах лимитов GitHub Pages (сайт ≤ 1 ГБ, трафик 100 ГБ/мес).
   - Для слов делаем 2 голоса (мужской и женский), чтобы привыкать к разным голосам.
2. **Для всего, чего нет в записи** (редкие случаи, свои фразы), фолбэк на Web Speech API с выбором en-GB-голоса.
3. Настройки: скорость 0.75× / 1× и кнопка «медленно».

Перед решением **прослушать образцы**: https://rhasspy.github.io/piper-samples/ (раздел en_GB). Если Piper не понравится, берём Kokoro `bf_emma`.

> Замечание: большинство твоих сериалов американские (Supernatural, Breaking Bad, Stranger Things), а GoT и LOTR британские. Британский голос в курсе + американская речь в сериалах = привыкнешь к обоим акцентам, это полезно для путешествий.

## 3. Геймификация: что работает, а что вредит

### Что говорят исследования

- **Метаанализ** (IJERPH 2021, 2010–2019): эффект геймификации положительный (d = 0,48). Но в коротких интервенциях (до недели) эффект **1,57**, до 20 недель **0,30**, а **на горизонте в годы он отрицательный (−0,20)**. Вывод: очки и значки быстро приедаются, если за ними нет реального прогресса.
- **Duolingo**: стрик сильнее всего мотивирует в начале (2 → 3 дня это +50%, 200 → 201 уже +0,5%). Анимация на майлстоунах стрика дала +1,7% к удержанию на 7-й день.
- **Теория самодетерминации (SDT)**: долго мотивирует ощущение **компетентности** («я реально стал понимать»), а не баллы сами по себе.

### Принципы для нашего приложения

1. **XP только за реальную работу**: правильные ответы, повторы, пройденные уроки. Нельзя «нафармить» XP, щёлкая лёгкое.
2. **Ранг = реальный уровень английского**. Ранг повышается только через **экзамен-«врата»**, а не через накопление XP. Тогда ранг честно отражает прогресс.
3. **Стрик с заморозками**: пропуск дня не обнуляет всё сразу. Заморозки зарабатываются.
4. **Показывать реальную компетентность**: «ты знаешь 847 слов = ~88% разговорной речи», «теперь ты понимаешь эту цитату из GoT, которую не понимал месяц назад».
5. **Без лиг и соревнований** (пользователь один), вместо них соревнование с собой: рекорды, недельная статистика.

### Система рангов в стиле Solo Leveling

Идея: ты «Охотник», который растёт от E-ранга до S-ранга. Каждый ранг привязан к уровню CEFR, переход через **«Врата»** (экзамен-данж).

| Ранг | CEFR | Условие перехода | Примерно при 1 ч/день |
|---|---|---|---|
| **E** | A0 → A1 (начало) | старт | 0 |
| **D** | A1 | Врата D: ~300 слов + to be, Present Simple, Present Continuous | ~1,5–2 мес. |
| **C** | A2 | Врата C: ~1000 слов + Past Simple, будущее, модальные | ~6 мес. |
| **B** | B1 | Врата B: ~2000 слов + Present Perfect, условные, разговорник | ~12 мес. |
| **A** | B2 | Врата A: ~3500 слов + все основные времена, пассив | ~18–24 мес. |
| **S** | C1 | Врата S: ~5000 слов + продвинутая грамматика | ~2,5 года |

Внутри ранга есть **уровни 1–N по XP** («Охотник D-ранга, ур. 7»), это даёт ощущение роста каждый день.

**Прочее:**
- **Ежедневные квесты** (как «Daily Quest» у Сон Джину): «пройди все повторения», «10 новых слов», «5 фраз в микрофон». Если выполнил все, получаешь бонус XP.
- **Достижения** по вселенным: «Winter is coming» (первые 7 дней стрика), «Saving people, hunting things» (100 правильных фраз подряд), «Equivalent exchange» (первые 1000 XP) и т.д.

### Цитаты из сериалов (Wikiquote)
Проверил объём на страницах по сезонам:
- **Supernatural (сезон 1): ~620 строк**. Это целые диалоги Сэма и Дина, очень простой разговорный английский, идеально для A1–A2. Например: *«I can't do this alone.» — «Yes, you can!» — «Yeah… Well, I don't want to.»*
- **Breaking Bad (сезон 1): ~285 строк**
- GoT, Stranger Things, FMA, AoT: другой формат страниц или мало цитат, придётся собирать вручную.
- Berserk, JJK, Solo Leveling: страниц нет, собираю вручную из английского дубляжа и известных мемов.

**Правило отбора:** короткие цитаты (1–2 реплики), с указанием сериала, сезона и эпизода, умеренное количество с каждого тайтла.

**Автоматическая разметка уровня:** для каждой цитаты считаем, какой % слов входит в изученные списки, и определяем грамматику. Цитата показывается, только когда ты знаешь ≥ 90% её слов (comprehensible input).

### Разговорник путешественника
Темы (сверено с Preply, EF): аэропорт → самолёт → паспортный контроль → транспорт → спросить дорогу → отель/хостел → кафе/ресторан → магазин → достопримечательности → small talk с местными → аптека/врач → экстренные ситуации. Диалоги напишу сам под уровни A1–B1.

## 5. Что дальше

Ресёрч в основном закрыт. Осталось:
1. **Файл от пользователя** с доп. источниками.
2. Прослушать образцы британских голосов и выбрать (Piper cori/alba или Kokoro emma).

Следующий этап: **дизайн приложения**.
- карта экранов (главная, урок, карточки, словарь, цитаты, разговорник, профиль охотника);
- программа курса: список модулей и уроков от E до S-ранга;
- формат данных (как хранятся урок, слово, цитата, карточка);
- стек и архитектура.
