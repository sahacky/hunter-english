# BOOT — Точка входа для AI-сессии

## Порядок чтения (ОБЯЗАТЕЛЬНО):
Вход — всегда через `AGENTS.md` (его автоматически читают все агенты; Claude Code — через `CLAUDE.md` → `@AGENTS.md`).
1. AGENTS.md — контекст проекта и все правила
2. Этот файл (BOOT.md)
3. WAL.md — текущее состояние
4. PLANS.md — что делать дальше

Если ты начал с BOOT.md — сначала прочитай AGENTS.md.

## Критические правила:
- Адресуй задачи: `plan://<майлстоун>#<задача>`
- Один коммит = одна задача
- Обновляй WAL в конце каждой сессии и после каждой задачи плана (с записью в Changelog)
- 4 варианта ответа на вопрос
- Спрашивай разрешение перед push
- **Перед началом задачи — подтверди понимание (см. AGENTS.md)**
- `research/` — источник правды по методике/данным/стеку; `example_rules/` — только примеры, не править

## Быстрые команды:
| Команда | Действие |
|---------|----------|
| `/status` | Показать текущее состояние |
| `/commit` | Предложить коммит |
| `/plan` | Показать следующую задачу |
| `/sync` | Перечитать WAL и PLANS |

## Если файл не найден:
- AGENTS.md отсутствует → создай по шаблону `example_rules/PROMT.md` после диалога
- WAL.md отсутствует → создай с "Current Phase: INIT" и пустым Changelog
- PLANS.md отсутствует → создай с пустым M1

## Подтверждение старта:
После чтения всех файлов выведи:
"✅ Контекст загружен. Готов к <задача>. Жду подтверждения."
