Смежные спеки: 08 (дизайн-система), спека формата данных / схемы БД (в подготовке — имена схем здесь логические).

## 1. Принципы навигации

1. **Hash-роутинг** (`/#/...`): статический SPA на GitHub Pages без серверных реврайтов; refresh и deep-link работают на любом маршруте.
2. **Офлайн-first, без авторизационных гардов**: приложение полностью работает без входа (Dexie/IndexedDB + статические JSON). `/#/login` нужен только для синхронизации; вход не блокирует ни один экран. Незалогиненному в местах sync показывается кнопка «Войти через GitHub».
3. **Прогресс сохраняется после каждого ответа** — навигация никогда не теряет данные (урок, сессия SRS); диалог-сценка при обрыве начинается заново (02 §5).
4. **Локаль и тема не в URL**: хранятся в `settings` + localStorage (ru/en, тёмная/светлая/системная).
5. Незнакомый маршрут → 404 (не редирект на главную молча).
6. Транзитные состояния (переворот карточки, открытие фидбэка) **не пишутся в history** (`replaceState`); шаги урока и фазы Врат — пишутся.

### Лейаут

| Брейкпоинт | Лейаут |
|---|---|
| ≥ 1200 px | 3 колонки: сайдбар 240 px + центр (учебная колонка ≤ 680 px) + правая панель 280 px (статус, квесты) |
| 768–1199 px | 2 колонки: сайдбар + центр; правая панель свёрнута в шапку (ранг, XP, стрик) |
| < 768 px | 1 колонка + нижний таб-бар из 5 пунктов; «Система»-панели = полноэкранные листы снизу |

Шапка (56 px): логотип-текст, мини-статус (ранг · уровень), переключатель локали, тема, настройки.

### 2.2 Дополнительные маршруты (M3+, нужны для целостности навигации)

| Маршрут | Экран | Примечание |
|---|---|---|
| `/#/path` | Путь обучения: юниты по рангам, состояния уроков (закрыт/доступен/пройден/«пора повторить»), «Правила юнита», контрольные каждые ~10 уроков, ссылка «Видео по теме» | Отсюда запускается `/#/lesson/:id`; с дашборда ведёт кнопка «Начать день» |
| `/#/welcome` | **Онбординг (первый вход, 2026-10-01, plan://onboarding)**: интро «Ты — Охотник. Система оценит твой ранг» → [Пройти оценку] / [Начать с нуля (E)]. Оценка: 12–16 фраз RU→EN по нарастанию E→A, адаптивно (полоса закрывается после 2 ошибок) → вердикт «Система назначает ранг X» → [Начать обучение]. Применение: ранг в статус, уроки ниже ранга — completed без XP, слова ниже полосы — suspend | Один раз (флаг в браузере); повторное открытие после прохождения — редирект на `/#/` |
| `/#/gates/S-FINAL` | Финальное испытание после ранга S: механика Врат (intro/exam/result) | Чеклист и пороги — из `gate_def`; не открывает новый ранг, даёт финальный статус охотника |
| `/#/dictionary` | Словарь: сила слов из FSRS, фильтры, карточка слова (значения, фразы, YouGlish/PlayPhrase) | Черновик — `research/06` §4.5 |
| `*` (любой неизвестный) | **404**: «Система не нашла такой узел», кнопки «На главную» и «Назад» | Ровно один обработчик, валидирует `:id`-параметры |

Валидация параметров: `:id` урока — `^(E|D|C|B|A|S)-\d{2}$`; `:from-:to` — `^(E-D|D-C|C-B|B-A|A-S)$` плюс особый id `S-FINAL`; `:situation` — slug из списка 10 ситуаций. Невалидные → 404.

## 4. Навигация

### 4.1 Что куда ведёт

| Откуда | Действие | Куда |
|---|---|---|
| Сайдбар / таб-бар | «Охотник» | `/#/` |
| Дашборд | «Начать день» | следующий шаг дня: `/#/srs/session?deck=due` → `/#/lesson/:id` → `/#/srs/session?deck=new` → слух/речь-шаги; после каждого шага возврат на `/#/` с обновлённым квестом |
| Дашборд, Словарь | квест-пункт «Повторы» | `/#/srs` |
| Путь, Дашборд | карточка урока | `/#/lesson/:id` |
| Урок (итог) | «Курс пути» / «Закрыть» | `/#/path` (из пути) или `/#/` (из «Начать день») |
| Статус | плашка «Врата D ≈ через N недель» | `/#/gates/E-D` |
| Цитата дня, Цитаты | плитка тайтла / цитата | `/#/quotes?title=…` / `/#/quotes/:id` |
| Цитата | слово (клик) | popover «в колоду» → карточка слова в `/#/dictionary` |
| Разговорник | карточка ситуации | `/#/phrasebook/:situation` |
| Настройки | «Аккаунт: войти» | `/#/login` |
| 404 | «На главную» | `/#/` |

### 4.2 Deep-links

- `/#/lesson/E-01?step=4` — открывает шаг 4; разрешён только для шагов ≤ «максимальный достигнутый + 1», иначе редирект на максимальный достигнутый.
- `/#/srs/session?deck=words|phrases|quotes|phrasebook|due&limit=10|20|all` — старт сессии с параметрами.
- `/#/gates/E-D?stage=intro|exam|result` — прямые ссылки на фазы; `exam` без активной попытки → редирект на `intro`.
- `/#/quotes/:id`, `/#/phrasebook/:situation` — шарабельные ссылки.
- Неизвестные/невалидные параметры → 404 (не молчаливая починка).

### 4.3 Back-поведение

| Контекст | Back / «←» |
|---|---|
| Дашборд, списки | обычный history.back |
| Урок, шаг N | «←» = шаг назад внутри урока; если введён непроверенный ответ — `Dialog` «Выйти на шаг назад? Ответ не проверен» |
| Урок → наружу (browser back, «✕») | `Dialog` «Урок не завершён. Прогресс сохранён — продолжите с шага N» [Продолжить урок / Выйти]; прогресс не теряется (чекпоинт после каждого ответа) |
| Урок, финал | back ведёт на `/#/path` или `/#/` (не возвращает в шаги) |
| Сессия SRS | «←» / Esc = `Dialog` «Прервать сессию? [N] повторов будет засчитано»; ответы уже записаны в `review_log` |
| Врата exam | «Прервать» с подтверждением; попытка аннулируется (не возобновляется) |
| Диалоги/popover | Esc / клик по подложке закрывают, фокус возвращается на триггер |

### 4.4 Guard на незавершённый урок

1. Каждый проверенный ответ пишет `lesson_progress {step, answers[]}` в IndexedDB (чекпоинт).
2. Открытие `/#/lesson/:id` с незавершённым прогрессом: экран выбора — «Продолжить с шага N» (primary) / «Начать заново» (ghost; перезаписывает ответы с подтверждением).
3. Deep-link `?step=` больше достигнутого — редирект на достигнутый шаг.
4. Завершённый урок всегда можно открыть заново («повторить тему») — прогресс оригинала не затирается, пишется как повтор.
5. Уход с урока при непроверенном вводе — единственный случай confirm-диалога (см. 4.3).

## 5. Доступность и клавиатура

### 5.1 Глобальные шорткаты (активны, если фокус не в поле ввода)

| Клавиша | Действие | Экран |
|---|---|---|
| `Space` | перевернуть карточку / показать ответ | SRS |
| `1`–`4` | оценка («Не вспомнил»/«Трудно»/«Хорошо»/«Легко»; в режиме 2 кнопок — `1`/`2`) | SRS |
| `Enter` | «Дальше» / «Проверить» | урок, SRS, диалоги |
| `R` / `S` | озвучка обычная / медленная | везде с аудио |
| `Esc` | закрыть диалог/popover, «прервать» с подтверждением | везде |
| `?` | панель шорткатов текущего экрана | урок, SRS |

Клавиши продублированы видимыми подписями на кнопках (`[Пробел] Показать ответ`) — десктоп; на мобилке подписи без клавиш.

### 5.2 Фокус и навигация

- **Focus ring всегда видим**: `outline: 2px solid var(--primary); outline-offset: 2px` через `:focus-visible`; отключение запрещено.
- Порядок таб-сплита = визуальному (сайдбар → центр → правая панель); skip-link «К основному содержимому».
- WordBank: чипы — кнопки; `Enter`/`Space` кладут слово в слот ответа, `Backspace` возвращает последнее; порядок озвучивается aria-live.
- Диалоги: focus trap, `role="dialog"/"alertdialog"`, возврат фокуса на триггер, закрытие по Esc.
- Плашка фидбэка и Toast — `aria-live="polite"`; ошибка — `role="alert"`.
- Оценка никогда не передаётся только цветом: diff + иконка + текст («лишнее слово», «опечатка»).
- Контраст: основной текст ≥ 7:1 на панели, `text-dim` ≥ 4.5:1, фокус ≥ 3:1.
- Тач-цели ≥ 44×44 px; подсказки клавиш скрыты на тач-устройствах.
- `prefers-reduced-motion` — см. спеку 08 §8.
