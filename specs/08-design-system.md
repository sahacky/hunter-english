# Спека 08: Дизайн-система («System window»)

> Дата: 2026-09-27. Статус: черновик v1 (M1).
> Источники: `research/06-ui-ux-competitors.md` §3 (стиль, токены-черновик, шрифты), `specs/04-gamification-spec.md` §9 (`game://style`), `specs/07-screens-navigation.md` §1 (лейаут, брейкпоинты), `research/00-summary.md`.
> Адресация: `spec://com.sahacky.hunter-english/specs/08-design-system.md#<якорь>`, внутри документа — короткие ID `ds://…`.
> Правило-основа (`game://style-yes/no`): исполнение полностью своё — без артов, логотипов, шрифтов-копий и звуков тайтла. Жанровые элементы (охотники, ранги E–S, Врата, статус-окна, голограммные панели) — общее достояние LitRPG.

## 1. Принципы {#principles}

| ID | Принцип |
|---|---|
| `ds://p-1` | Тёмная тема — основная, светлая — полноправная (WAL → Decisions Made). Все цвета — только через токены (§2), хардкод HEX в компонентах запрещён. |

## 1a. Тема «Daylight» — выбранное направление v2 (2026-10-02) {#daylight}

> Решение разработчика после просмотра трёх превью (`/design-preview/`): основное направление — **B «Daylight»** — светлый, дружелюбный, крупные скругления, мягкие тени. Текущая «System window» уходит; тёмная тема остаётся парной (Daylight-Dark — та же геометрия и характер, приглушённые цвета фона). Реализация — plan://theme-daylight.

### Токены light (основная)

| Токен | Значение | Комментарий |
|---|---|---|
| `--bg` | `#F6F8F4` | молочный с зелёным подтоном |
| `--surface` | `#FFFFFF` | карточки |
| `--surface-2` | `#F0F7F2` | вложенные блоки, инпуты, hover |
| `--mint` | `#D8F3E6` | чипы, выполненные пункты, акцент-фон |
| `--primary` | `#2FB47C` | основной акцент (зелёный) |
| `--primary-deep` | `#17845C` | текст на mint, ссылки |
| `--gold` | `#FFB703` | квесты, таймер дня, «ты здесь» |
| `--gold-soft` / текст | `#FFF2D9` / `#A26A00` | тёплый чип |
| `--danger` | `#FF7A66` / фон `#FFE4DE` / текст `#B3402C` | «не вспомнил», ошибки |

### Форма и движение

| Свойство | Значение |
|---|---|
| Радиус карточки / кнопки / пилюли | 24 / 16 / 999px |
| Тень | только `--shadow` (никаких glow/свечений) |
| Углы | прямые, без `clip-path`-скошенностей |
| Шрифт | **Nunito** self-host (SIL OFL): 400/600/800/900 + italic 400, subsets cyrillic+latin; fallback `'Golos Text', system-ui`; моно — сохранить текущий |
| Кнопка primary | фон `--primary`, текст белый, `box-shadow: 0 3px 0 rgba(31,42,36,.08)`; active — сдвиг 2px |
| Кнопка-«нажатие» | приём из превью B: `translateY(2px)` на `:active` |
| Прогресс | точки-сегменты или кольцо (conic-gradient) вместо неоновой полосы |
| Анимации | 150–250 мс; `prefers-reduced-motion` — как в §8 |

### Парная тёмная (Daylight-Dark)

Та же геометрия/типографика; фоны: `--bg #17211C`, `--surface #1F2B25`, `--surface-2 #29392F`, `--mint #23483A`, `--primary #3EC98D`, текст `#E8F2EA` / dim `#93A69B`, границы `#31443A`. Контраст — по `ds://p-3` (≥7:1 на панели).

### Что удаляется из v1

Скошенные углы панелей, glow-рамки, hex-бейдж ранга, scanline-фактура, IBM-Plex-заголовки-плашки `[ ... ]` в квадратных скобках (заголовки обычные, serif-неон не возвращается).

## 4. Сетка, отступы, брейкпоинты {#layout}

### 4.1 Отступы {#layout-spacing}

Токены: `--space-1: 4px`, `--space-2: 8px`, `--space-3: 16px`, `--space-4: 24px`, `--space-5: 32px`.

| Где | Значение |
|---|---|
| внутри чипа/кнопки (верт./гориз.) | 8 / 16 (`space-2 / space-3`) |
| между элементами формы, пунктами квеста | 8–12 |
| внутренние поля панели | 16–24 |
| между панелями | 24–32 |
| секции экрана | 32 |

### 4.2 Контейнер и брейкпоинты {#layout-breakpoints}

Контейнер: `max-width: 1200px`, центрирован. Учебная колонка ≤ 680 px даже на десктопе (06 §4.11). Лейаут по колонкам — 07 §1.

| Диапазон | Лейаут | Навигация |
|---|---|---|
| ≥ 1200 px | 3 колонки: сайдбар 240 + центр (≤ 680) + правая панель 280 | сайдбар |
| 768–1199 px | 2 колонки: сайдбар + центр; статус свёрнут в шапку | сайдбар |
| < 768 px | 1 колонка; панели Системы = полноэкранные листы снизу; blur/свечение упрощены | нижний таб-бар из 5 пунктов |

Тач-цели ≥ 44×44 px; safe-area для PWA (`env(safe-area-inset-*)`).

## 5. Компоненты и состояния {#components}

Общие состояния: **hover** — фон `--surface-2` / рамка `--primary`; **active** — затемнение/сжатие 1 px, свечение усиливается; **disabled** — `opacity: .45`, без свечения, курсор `not-allowed`; **focus** — `outline: 2px solid var(--primary); outline-offset: 2px` через `:focus-visible`, отключение запрещено (07 §5.2). Переходы всех состояний 150 мс.

### 5.1 Сводная таблица {#components-table}

| Компонент | Назначение | Ключевые состояния |
|---|---|---|
| `Button` | primary / secondary (primary-dim) / ghost / danger | hover: рамка+свечение; active: сжатие; disabled; focus; loading (спиннер вместо текста) |
| `Card` | панель-окно Системы с уголками и свечением | обычное / warn (рамка warn) / danger (красное окно) / gold (ранг, титул); открытая/закрытая анимация (§8) |
| `RankBadge` | ромб-бейдж E–S | по рангу (§2.3); с подписью/без; locked ( серый, замок) |
| `ProgressBar` | XP до подуровня, шаги урока, % ситуации | заполнение цветом смысла (primary/success/gold); анимация заполнения 250 мс; `aria-valuenow` |
| `QuestItem` | строка квеста: чекбокс + название + счётчик `[6/10]` | `☐/☑`; при выполнении — вспышка чекбокса, счётчик прокручивается (06 §3.2); счётчик — mono |
| `Flashcard` | карточка SRS | вопрос → переворот (Space/тап); после переворота — кнопки оценки 2/4 с интервалами в mono; сила слова цветом |
| `WordBank` | чипы слов для сборки фразы | чип = кнопка: hover поднимает, active утапливает; использованный чип гаснет; Backspace возвращает; порядок озвучивается aria-live (07 §5.2) |
| `Input` (с diff) | ввод фразы, диктант | focus — рамка primary; после проверки — diff-подсветка (§5.2); `autocapitalize="off"`, `spellcheck="false"` (06 §4.11) |
| `Dialog` | «системное сообщение»: подтверждения, награды, отчёты | info (primary) / danger / gold; focus trap, Esc, возврат фокуса; появление — анимация окна (§8) |
| `Toast` | короткие уведомления (не блокируют) | 3 с, aria-live polite; максимум 1 одновременно; «Всё повторено», «Скопировано» |
| `Skeleton` | загрузка панелей/списков | пульс 1.5 s; форма повторяет контент (панель/строка/карточка); отключается в reduced-motion |

### 5.2 Card — панель с уголками и свечением {#components-card}

```
  ┏━━ FRAME ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓      углы: скос 12px (clip-path polygon)
  ┃ ⬡ [ ЕЖЕДНЕВНЫЙ КВЕСТ ]        09:41  ┃      заголовок-плашка: caption-caps, рамка снизу
  ┃                                       ┃      рамка: 1px var(--primary) + --glow
  ┃   ☑ Повторы            [142/142]     ┃      тело: bg var(--surface), текст --text
  ┃   ☐ Новые слова       [  6/10]       ┃      счётчики: JetBrains Mono, --text-dim
  ┃                                       ┃
  ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

  clip-path: polygon(12px 0, calc(100% - 12px) 0, 100% 12px,
                     100% calc(100% - 12px), calc(100% - 12px) 100%,
                     12px 100%, 0 calc(100% - 12px), 0 12px);
```

Варианты: `danger` — рамка `--danger` + красное свечение; `gold` — рамка `--warn` + золотое свечение. В светлой теме свечение отключено, скосы и плашка сохраняются.

### 5.3 Input с diff-подсветкой {#components-input-diff}

После проверки ответ сравнивается по словам (03 §3): верное — обычный текст, опечатка — жёлтое подчёркивание (засчитано), лишнее слово — перечёркнутое красным, пропущенное — зелёная вставка.

```
  Сценарий А — ловушка (не засчитано):
  Ввод:   i go to home
  Верно:  I go home
  ─────────────────────────────────────
  I  go  ~~to~~  home        ✗ «⚠ I go home (без to)» ← ЛТ-02

  Сценарий Б — опечатка (засчитано с подсветкой):
  Ввод:   I arrve late
  Верно:  I arrive late
  ─────────────────────────────────────
  I  arrve  late             ✓ засчитано с опечаткой: arrve → arrive
                             (жёлтая волнистая линия)
```

Опечатка никогда не только цветом: рядом текст причины («опечатка», «лишнее слово») — 07 §5.2.

## 7. Анимации {#motion}

Токены: `--dur-fast: 150ms`, `--dur: 200ms`, `--dur-slow: 250ms`; easing `cubic-bezier(.2,.6,.2,1)`.

| Событие | Длительность | Что происходит |
|---|---|---|
| hover/active/focus | 150 | фон, рамка, свечение |
| ProgressBar заполнение | 250 | ширина, ease-out |
| Toast / фидбэк-плашка | 200 | выезд снизу + fade |
| Появление окна Системы | 120+180 | линия 120 мс → раскрытие по высоте 180 мс → текст построчно 30–50 мс/строку (game://style-anim) |
| «Квест выполнен» | 200 | вспышка чекбокса, прокрутка счётчика |
| Повышение ранга | 2000–3000 | кат-сцена: бейдж собирается из линий; всегда кнопка «Пропустить» |
| Урок | 0–150 | минимум анимаций — не отвлекать от фразы (06 §3.2) |

`prefers-reduced-motion: reduce`: построчный текст и кат-сцены заменяются мгновенным показом, скелетоны без пульса, scanlines выкл.; настройка «Анимации: полные / мягкие / выкл» в Настройках перекрывает системную (07 §2.1).

## 8. i18n и форматирование {#i18n}

1. Ни одной хардкод-строки UI: только `t('key')` (react-i18next); новый ключ добавляется сразу в `src/locales/ru.json` и `en.json` (AGENTS.md → Локализация).
2. Учебный контент (`data/`) — не UI-строки: поля `text_en` / `translation_ru` / `rule_md` лежат в данных (05 §0).
3. Множественные числа — механизм plural i18next: `t('srs.cards_left', {count})`; формы ключа: ru — 4 формы `_one/_few/_many/_other`, en — `_one/_other`. Счётчики вида `[3/10]` — сами цифры не локализуются, подпись — ключ.
4. Даты и время — только `Intl`: `Intl.DateTimeFormat(locale)` (дата в шапке, «до конца дня»), `Intl.RelativeTimeFormat` («через 5 недель»), `Intl.NumberFormat` (проценты, XP). `locale = i18n.language`.
5. Граница дня — 4:00 локального времени (srs://day-boundary); таймеры считаются в локальном часовом поясе устройства, без ручных смещений.
6. Тон «Системы» сохраняется в обеих локалях: короткие фразы, квадратные скобки, обращение «Охотник» / «Hunter» (game://style-i18n).
7. Названия тайтлов (Supernatural, GoT…) и цитаты — не переводятся; переводы цитат хранятся в данных (`quote.translation_ru`, 05 §5).

## Открытые вопросы {#open-questions}

1. Светлая тема: HEX из §2.2 первичные — прогнать контраст-чекером в M2, особенно `warn` (#9A6A00) и `primary` (#1D7FB8) на белом.
2. Заголовочный шрифт: Tektur основным или Russo One (угловатее, но один вес)? Оставить оба как пару «заголовок/акцент»?
3. Фиолетовый `--accent-2`: только A-ранг и кат-сцены или шире (бонус-квесты, редкие достижения)? Нужен ли второй неон в обычном UI?
4. Scanline-оверлей: включён по умолчанию с прозрачностью ≤ 4% или выключен (производительность слабых машин)?
5. Степень упрощения на мобилке: полностью отключать blur/свечение < 768 px или по детекции производительности (fps-монитор)?
6. Бейдж ранга: ромб (§2.3) или шестиугольник «Системы» — нужен макет-сравнение в M2.
7. Иконки заморозок/стрика: lucide `Snowflake`/`Flame` достаточно или рисовать свои в стиле Системы (ромбическая огранка)?
8. Хранение шрифтов: `@fontsource/*` пакетами или self-hosted woff2 в `src/assets/fonts` (влияет на размер бандла и PWA-кэш)?
