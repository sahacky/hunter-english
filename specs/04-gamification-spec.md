## 1. Принципы {#principles}

| ID | Принцип |
|---|---|
| `game://p-1` | **XP только за реальную работу**: проверенные приложением ответы, повторы, уроки. Самоотчёта нет, «нафармить» щёлканьем лёгкого нельзя (02 §3). |
| `game://p-2` | **Ранг = реальный уровень английского.** Повышается только через экзамен «Врата», а не накоплением XP. |
| `game://p-3` | **Без наказаний**: нет HP/урона за пропуск, лиг, «жалобных» пушей, покупки заморозок. Цена провала Врат — только повторение материала. |
| `game://p-4` | **Показываем компетентность, а не баллы**: «знаешь 847 слов ≈ 88% разговорной речи», «сейчас ты понимаешь эту цитату, месяц назад — нет». |
| `game://p-5` | Соревнование только с собой: рекорды, недельная статистика, heatmap (06 §1.13). |
| `game://p-6` | Вся «косметика» стиля — своя, без артов/логотипов/звуков тайтла (game://style). |

## 2. Ранги и уровни {#ranks}

`srs://day-boundary` (спека SRS) используется здесь как граница дня для стрика, квестов и XP-капов.

### 2.1 Ранги E→S = CEFR {#ranks-table}

| Ранг | CEFR | Врата (экзамен) | Слова | Грамматика (примерный объём) | Срок при 1 ч/день |
|---|---|---|---|---|---|
| **E** | A0 → A1 | старт (нет) | — | — | 0 |
| **D** | A1 | Врата D | 300 | to be, Present Simple, Present Continuous | ~1,5–2 мес. |
| **C** | A2 | Врата C | 1000 | can, have got, there is/are, some/any/much/many, повелительное, Present Simple vs Present Continuous | ~6 мес. |
| **B** | B1 | Врата B | 1800 | Present Perfect (vs Past Simple), условные 0/1/2, пассив базово, косвенная речь, фразовые глаголы (топ-100) | ~12 мес. |
| **A** | B2 | Врата A | 2800 | все 8 основных времён, пассив все формы, wish, should have, relative clauses | ~18–24 мес. |
| **S** | C1 | Врата S | 4000 | 3rd conditional, смешанные условные, инверсия (обзорно), пунктуация | ~2,5 года |

### 2.2 Уровни внутри ранга {#levels}

`game://levels` — внутри ранга бесконечные подуровни, запись **ур. E-1, ур. E-2, ур. E-3…** («Охотник D-ранга, ур. D-7» — как в 02 §3).

| Параметр | Значение |
|---|---|
| Порог подуровня n → n+1 | `100 + 25 × (n − 1)` XP суммарного счётчика текущего ранга |
| Пересечение ранга | счётчик XP уровня сбрасывается на 0, подуровень снова 1 (ур. D-1, ур. C-1…) |
| Смысл | давать ощущение роста каждый день; на ранг и Врата не влияет |
| Ожидание | при типичных ~200–300 XP/день в ранге D к моменту Врат C — примерно 15–20-й уровень |

Прогресс-бар до Врат: `game://gate-progress`.

## 3. Врата {#gates}

`game://gates` — экзамен-«данж» в конце ранга. Экран-вход и результат — по research/06 §4.9: чеклист готовности, секции без подсказок и фидбэка до конца, при провале — список слабых тем и автогенерация «Плана подготовки» (в путь и колоду).

### 3.1 Состав экзамена {#gates-sections}

| Секция | Формат | Заданий | Порог |
|---|---|---|---|
| Лексика | EN→RU и RU→EN (выбор + ввод) | 20 | ≥ 80% |
| Грамматика | переводы фраз, найди ошибку, поставь время | 20 | ≥ 80% |
| Слух | диктант фраз + «выбери, что услышал» | 15 | ≥ 80% |
| Речь | «скажи вслух» / ответь на вопрос голосом | 10 | ≥ 80% |

Общий порог сдачи: **все секции ≥ 80% и сумма ≥ 85%**. Провал любой секции = провал экзамена, даже при высоком общем результате.

### 3.2 Правила попыток и цена провала {#gates-retry}

| ID | Правило |
|---|---|
| `game://gate-open` | Врата открыты всегда (чеклист требований — рекомендация готовности, не замок). Вход — по подтверждению «Ты готов?». |
| `game://gate-cooldown` | Повторная попытка — не раньше чем через **72 часа** после провала. |
| `game://gate-retry-sections` | Пересдача по секциям: неудовл. секции сбрасываются, сданные сохраняются. |
| `game://gate-fail` | Цена провала — **только повторение**: «План подготовки» из слабых тем; без штрафов, без потери XP/стрика/уровней. |
| `game://gate-win` | При успехе: новый ранг, золотое окно Системы (game://style), короткая анимация (06 §3.2), +200 XP. |
| `game://gate-content` | Контент Врат — из пройденных юнитов ранга + разговорник (диалог-сценка — с ранга D). Контрольные юнитов — тренировка перед Вратами (00-summary). |

## 4. XP {#xp}

`game://xp` — XP начисляется только за проверенные ответы и завершённые единицы работы. Больше за сложное: ввод дороже выбора, голос дороже ввода (06 §1.12).

### 4.1 Таблица XP {#xp-table}

| Действие | XP за единицу | Примечание |
|---|---|---|
| Упражнение урока — выбор из 3–4 | 1 | «разогрев» |
| Упражнение урока — ввод текстом | 2 | основная работа |
| Упражнение урока — голосом | 3 | |
| Word-bank (сборка фразы) | 2 | |
| Cloze (пропуск в цитате) | 2 | |
| Find-error (найди ошибку) | 3 | |
| Tense-choice (выбор времени) | 3 | |
| Transform (трансформация) | 3 | |
| Answer-question (ответ на вопрос) | 4 | |
| Speak (скажи вслух) | 4 | |
| Dialogue-scene (диалог-сценка) | 5 | +2 за реплику пользователя |
| Повтор карточки (любая оценка) | 1 | работа сделана даже при «Не вспомнил» |
| Новая карточка выпущена в Review | 2 | завершение learning |
| Диктант: верная фраза | 3 | зачёт по правилам 03 §3 |
| Shadowing: фраза (распознавание ≥ 80%) | 3 | |
| Урок пройден (первый раз) | +25 бонус | сверх XP за упражнения |
| Контрольная сдана | 50 | |
| Мини-тест словаря VLT (srs://vlt) | 40 | |
| Ежедневный квест: все 3 слота | +30 | |
| Бонус-квест дня | +15 | |
| Врата пройдены | 200 | |

### 4.2 Анти-абьюз: дневные капы и правила {#xp-caps}

Капы считаются по локальному «дню обучения» (граница 4:00).

| Ограничитель | Значение |
|---|---|
| Повторы карточек | ≤ 200 XP/день (200 XP ≈ 200 повторов; при 15 новых ≈ 150) |
| Упражнения-«выбор» | ≤ 30 XP/день, дальше — XP только за ввод/голос |
| Упражнения голосом | ≤ 60 XP/день |
| Диктант | ≤ 60 XP/день |
| Shadowing | ≤ 45 XP/день |
| Бонус урока (+25) | только первый урок дня; последующие — +10 |
| Повтор уже пройденного урока | XP упражнений 50%, бонуса нет; не чаще 1 раза в день на урок |
| Пересдача контрольной | без XP |
| XP не начисляется за | чтение правила, просмотр цитат/разговорника, открытие экранов, озвучку без ответа |

Ориентир: типичный день ~200–300 XP; потолок при полной программе ~500.

## 5. Стрик и заморозки {#streak}

`game://streak` — серия дней занятий.

| ID | Правило |
|---|---|
| `game://streak-day` | День засчитан, если выполнен **хотя бы один пункт ежедневного квеста** (game://quests). Слоты квеста построены так, что минимальный пункт ≈ 10 повторов — «спасительный режим» для плохих дней (06 §1.10). |
| `game://streak-window` | Окно дня — то же, что у SRS: **4:00 локального времени** (srs://day-boundary). |
| `game://freeze` | **Заморозки**: стартовый запас **2**, максимум **5** на счету. Начисление: **+1 за каждые 7 дней серии подряд**. Не покупаются (06 §1.1). |
| `game://freeze-auto` | Пропущенный день закрывается заморозкой **автоматически**, серия сохраняется; окно «Заморозка использована». |
| `game://streak-break` | Пропусков подряд больше, чем заморозок → серия обнуляется. Ручного «ремонта» и покупок нет. Рекорд серии хранится отдельно. |
| `game://streak-ui` | Стрик показывается мягко: без пушей-вины, анимация только на майлстоунах (7/30/100 дней) (02 §3, 06 §1.1). |

## 6. Ежедневные квесты {#quests}

`game://quests` — окно «Ежедневный квест» на главной (research/06 §4.1): 3 фиксированных слота + рандомный бонус, чекбоксы, счётчики `[3/10]`, таймер до 4:00.

| Слот | Квест | Объём |
|---|---|---|
| 1 | «Повтори карточки» | N = все due на день (минимум 20 для счёта) |
| 2 | «Пройди урок» | 1 урок по пути |
| 3 | «Диктант» | 10 фраз |
| Бонус | случайный из пула | фиксирован на день (seed по дате, без переролла) |

Пул бонус-квестов (старт): скажи вслух 5 фраз · shadowing 5 фраз · cloze по 3 цитатам · найди пары 10 слов · диалог-сценка разговорника · мини-«найди ошибку» 5 фраз.

Награды: XP за сами действия (game://xp-table) + бонус за все 3 слота (+30) + бонус-квест (+15). Выполнение любого слота закрывает день для стрика.

## 8. Прогресс-бар до Врат {#gate-progress}

`game://gate-progress` — на экране ранга/пути: чеклист готовности к следующим Вратам (по game://gates-content): «слова ≥ N» (прогресс X/N), «темы грамматики освоены» (да/нет по дашборду), «контрольные юнитов сданы». Под чеклистом прогноз в духе Busuu: «Врата D ≈ через 5 недель при текущем темпе» (по скользящим 14 дням XP и слов).

## 9. Стиль «System window» {#style}

`game://style` — визуальный язык по мотивам Solo Leveling, но **полностью оригинальное исполнение** (06 §3.2–3.3 — источник правды по токенам).

| ID | Правило |
|---|---|
| `game://style-yes` | Жанровые элементы LitRPG: охотники, ранги E–S, врата, ежедневные квесты, статус-окна, голубые голографические панели. Свои: палитра (`--line #4FC3F7`, фон `--bg #070B14`, панели `rgba(12,28,52,.82)`), шрифты с кириллицей (Tektur/Russo One — заголовки; Onest/Golos Text — текст; JetBrains Mono — счётчики), свои иконки (ромб/шестиугольник), скошенные углы окон. |
| `game://style-no` | **Запрещено**: название тайтла в UI, логотип, персонажи, кадры, арты, фанатские шрифты-копии, рипы звуков, дословные формулировки окон тайтла. Звук — только свой синтез (Web Audio) или CC0-библиотеки, выключаемый. |
| `game://style-text` | **Текст-паттерн системного сообщения**: заголовок-плашка в квадратных скобках («[Уровень повышен]»), короткие строки тела, счётчики в скобках («[3/10]»), адрес к пользователю — «Охотник». Цвет окна по смыслу: синий — информация/награда, красный — предупреждение/провал, золотой — ранг/редкое достижение. |
| `game://style-anim` | Появление: линия 120 мс → раскрытие 180 мс → текст построчно; учитывается `prefers-reduced-motion`; в уроке анимации минимальны (06 §3.2). |
| `game://style-i18n` | Все тексты окон — ключи i18n (`ru`/`en`), тон «Системы» сохраняется в обеих локалях. |
| `game://style-disclaimer` | В README: «вдохновлено жанром LitRPG / системными интерфейсами; не связано с правообладателями». |

## 11. Открытые вопросы {#open-questions}

1. Пороги подуровней (`100 + 25 × (n − 1)`) — первичные; проверить ощущение роста на первом месяце.
2. Коэффициенты капов XP (game://xp-caps) — откалибровать по реальному дню в M7.
3. Cooldown Врат 72 ч и пороги секций 80%/85% — подтвердить после первой сдачи Врат D.
4. Заморозки: старт 2 / максимум 5 — подтвердить.
5. Состав пула бонус-квестов на старте (6 штук) — расширить после M5–M6 (когда есть голос и разговорник).
6. Какие цитаты брать для новых титулов достижений — согласовать с research/05 (объёмы по тайтлам).
7. Нужен ли отдельный «дневной отчёт» окном при каждом закрытии сессии или только при закрытии всех блоков дня?
